- 问题出在 E2E 测试的内容检测选择器

**根因发现：** `text_content()` 在 Element Plus textarea 上无效

```python
# 错误方式（Element Plus textarea 不积累 textContent）

# 正确方式（v-model 绑定的是 input value）
txt = textarea.input_value()
```
